My Projects

Smart Hostel Access & Room Key System (SHARKS)

The Smart Hostel Access & Room Key System is designed to modernise hostel room security using an LED key panel and a dedicated scanning device. The system allows residents to access their rooms without relying on a traditional physical key.

The scanning device authenticates each resident and communicates with the panel to grant or deny access. This approach is intended to improve convenience and security compared with traditional lock-and-key systems.
