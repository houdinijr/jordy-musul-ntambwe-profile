Smart Hostel Access & Room Key System (SHARKS)

A smart access control system designed to modernise hostel room security using an LED key panel and a dedicated scanning device, allowing residents to unlock their rooms without a traditional physical key.

The scanning device authenticates each resident and communicates with the panel to grant or deny access in real time, improving both convenience and security compared to traditional lock-and-key systems.
